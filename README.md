# Portfólio — Miguel Romão

Site pessoal com meus projetos, tecnologias, experiência e formação. É uma página estática (HTML, CSS e JavaScript puro), sem build e sem dependências.

**Site:** https://romaomiguel.github.io/Portifolio

## Estrutura

```
index.html            conteúdo da página
style.css             estilos (tema claro e escuro)
script.js             dados dos projetos, vitrine e tecnologias
assets/projetos/      capturas de tela dos projetos em destaque
```

## Como editar

- **Projetos em destaque:** edite a lista `DESTAQUES` no início do `script.js`. Cada item tem nome, resumo, pontos, tecnologias, imagem e o campo `aberto` (`true` se o repositório é público).
- **Outros projetos:** lista `MAIS`, no mesmo arquivo.
- **Tecnologias:** lista `TECH`, no mesmo arquivo.
- **Textos de experiência e formação:** direto no `index.html`.

## Rodar localmente

Abra o `index.html` no navegador. Não precisa de servidor.

## Observações

As capturas de tela dos projetos mostram dados fictícios. Os projetos de uso real estão publicados em versão anonimizada, sem dados de clientes.
